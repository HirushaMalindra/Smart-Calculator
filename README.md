# Smart Calculator Plus

Build a modern version calculator mobile app. With all of the advance features and also include  rotate feature, theam color change feature and a clipboard as well.

This project was built with [Lovable](https://lovable.dev).

## Build with Lovable

```sh
git clone <this-repository-url>
```
